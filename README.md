## Core Capabilities

- **Financial Analytics**: Cash inflow, expenditure outflow, net surplus/deficit, and annualized savings rate tracking.
- **Calibrated ML Categorization**: Gradient Boosting classifier (`CalibratedClassifierCV`) providing probabilistic certainty metrics on each transaction.
- **Ledger Management**: Full-text transaction search, multi-filter ledger explorer, manual journal entries, and batch CSV export.
- **Budget Surveillance**: Category-level expenditure ceilings, variance analysis, and live utilization tracking.
- **Target Tracking**: Capital goals with milestone projections and deficit alerts.
